`djalthingi` is a [Django](https://www.djangoproject.com/) app that downloads data from the [Icelandic Parliament](https://www.althingi.is).

It is used by other projects such as [Lagasafn-XML](https://github.com/althingi-net/lagasafn-xml) and [ChaosTemple](https://github.com/althingi-net/chaostemple).

If you are only interested in getting the data, it might be wiser to reach out to the author and ask if the database can be distributed by downloading an SQLite database or even an SQL dump, or by using an already running instance with a functioning API.

Once a public API is established in production mode, it will be noted here.
